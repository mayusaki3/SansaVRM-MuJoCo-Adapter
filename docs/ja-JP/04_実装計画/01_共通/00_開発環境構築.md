# 開発環境構築

## 1. 本ドキュメントの目的

本ドキュメントは、SansaVRM-MuJoCo-Adapter の共通開発環境構築方針を定義する。

本ドキュメントでは、リポジトリ取得、ブランチ運用、Python 仮想環境、依存関係、Git 管理対象外ファイル、ドキュメント運用、テスト実行手順の初期方針を整理する。

## 2. 対象環境

初期対象環境は以下とする。

- Windows 10 / Windows 11
- PowerShell
- Git
- Python 3.10 以上
- Python 仮想環境 `.venv`
- PyPI package `mujoco`

Linux / macOS は、別途検証後に追記する。

## 3. リポジトリ取得

作業ディレクトリ例は以下とする。

```powershell
cd C:\WORKPLACE\Makes\GitHub
git clone https://github.com/mayusaki3/SansaVRM-MuJoCo-Adapter.git
cd SansaVRM-MuJoCo-Adapter
```

## 4. ブランチ方針

初期開発では `develop` ブランチを使用する。

```powershell
git checkout develop
```

安定版は将来的に `main` へ反映する。

作業単位が大きくなる場合は、feature ブランチを使用する。

例：

```text
feature/local-mujoco-validation
feature/mjcf-writer
feature/controller-config
```

## 5. Python仮想環境

リポジトリ直下に `.venv` を作成する。

```powershell
py -3 -m venv .venv
```

仮想環境を有効化する。

```powershell
.\.venv\Scripts\Activate.ps1
```

PowerShell の実行ポリシーにより有効化できない場合は、現在ユーザーの実行ポリシーを変更する。

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

## 6. pip更新

```powershell
python -m pip install --upgrade pip
```

## 7. 依存関係インストール

依存関係は `requirements-dev.txt` に定義する。

```powershell
pip install -r requirements-dev.txt
```

初期依存関係は以下とする。

```text
mujoco>=3.3.0
numpy>=1.26
pytest>=8.0
pytest-cov>=5.0
jsonschema>=4.0
```

## 8. MuJoCo import確認

```powershell
python -c "import mujoco; print(mujoco.__version__)"
```

期待結果：

- エラーなく `mujoco` を import できる
- MuJoCo version が表示される

## 9. pytest実行

pytest はリポジトリ直下で実行する。

```powershell
pytest
```

期待結果：

- `tests/` 配下のテストが実行される
- `src/sansavrm_mujoco_adapter` を import できる
- MuJoCo viewer に依存しない headless テストが実行される

## 10. coverage実行

coverage を確認する場合は、以下を実行する。

```powershell
pytest --cov=src/sansavrm_mujoco_adapter --cov-report=term-missing
```

単体テスト対象モジュールの coverage は 100% を必須とする。

ただし、MuJoCo viewer、OS / GPU / OpenGL 依存箇所、外部 runtime 依存箇所は単体テスト対象から分離する。

## 11. ドキュメント運用

ドキュメントは、原則として `docs/<language-code>/` 配下で管理する。

日本語ドキュメントは以下に配置する。

```text
docs/ja-JP/
```

日本語ドキュメントの入口は以下とする。

```text
docs/ja-JP/目次.md
```

ドキュメントは HLDocS 形式に従う。

作成する Markdown ドキュメントには、以下を含める。

- LLM-MANAGED ブロック
- 先頭の階層リンク
- タイトル
- 本文
- `---`
- 末尾の階層リンク

## 12. 目次リンク方針

`docs/ja-JP/<大分類>/<小分類>/<文書>.md` から `docs/ja-JP/目次.md` へ戻る相対パスは以下とする。

```markdown
[目次](../../目次.md)
```

`docs/ja-JP/目次.md` から README へ戻る相対パスは以下とする。

```markdown
[README](../../README.md)
```

## 13. Git管理対象

以下は Git 管理対象とする。

- README.md
- LICENSE
- .gitignore
- requirements-dev.txt
- pyproject.toml
- docs/
- examples/
- schemas/
- src/
- tests/

ただし、`examples/` 配下でも巨大なバイナリ、外部から取得したモデル、個別環境依存の成果物は Git 管理対象外とする。

## 14. Git管理対象外

以下は Git 管理対象外とする。

- `.venv/`
- `.env`
- `.env.*`
- `output/`
- `outputs/`
- `artifacts/`
- `logs/`
- `*.log`
- `*.mjb`
- `*.mjcf.compiled.xml`
- `controller_config.local.json`
- `conversion_report.local.json`
- `diagnostics.local.json`
- `test_report.local.json`
- `local/`
- `tmp/`
- `temp/`
- `sandbox/`
- `assets/local/`
- `models/local/`

## 15. 初期確認手順

初期確認は以下の順で行う。

1. `git status` を確認する
2. `develop` ブランチであることを確認する
3. `.venv` を作成する
4. 依存関係をインストールする
5. `mujoco` を import できることを確認する
6. 最小 MJCF モデルを読み込めることを確認する
7. `mj_step` を実行できることを確認する
8. `pytest` を実行できることを確認する
9. coverage を確認できることを確認する

## 16. 完了条件

共通開発環境構築の完了条件は以下とする。

- リポジトリを取得できる
- `develop` ブランチで作業できる
- `.venv` を作成できる
- `requirements-dev.txt` に基づいて依存関係をインストールできる
- `mujoco` を import できる
- `pytest` を実行できる
- coverage を確認できる
- Git 管理対象外ファイルが `.gitignore` で除外されている
- ドキュメントが HLDocS 形式で配置されている

## 17. 次工程

共通開発環境構築後、以下へ進む。

1. ローカル MuJoCo 環境構築
2. ローカル動作確認
3. 最小 MJCF 検証計画
4. pytest によるローカル動作確認テスト実装
5. MJCF 読み込みテスト実装
