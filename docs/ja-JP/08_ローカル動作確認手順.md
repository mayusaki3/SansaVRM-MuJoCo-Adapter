# ローカル動作確認手順

## 1. 目的

本ドキュメントは、ローカル MuJoCo 環境が SansaVRM-MuJoCo-Adapter の検証環境として使用可能か確認するための手順を定義する。

本手順では、最小 MJCF モデルを対象に以下を確認する。

- MJCF ファイルを読み込める
- `MjModel` を生成できる
- `MjData` を生成できる
- `mj_step` を実行できる
- body / joint / geom 数を取得できる

## 2. 前提

以下が完了していること。

- `docs/ja-JP/07_ローカルMuJoCo環境構築.md` の手順を実施済み
- 仮想環境 `.venv` を作成済み
- `pip install -r requirements-dev.txt` を実行済み
- `examples/minimal_body/model.xml` が存在する

## 3. 手動確認

PowerShell で仮想環境を有効化する。

```powershell
.\.venv\Scripts\Activate.ps1
```

MuJoCo import を確認する。

```powershell
python -c "import mujoco; print(mujoco.__version__)"
```

最小モデルを読み込む。

```powershell
python -c "import mujoco; m=mujoco.MjModel.from_xml_path('examples/minimal_body/model.xml'); d=mujoco.MjData(m); mujoco.mj_step(m,d); print('ok', m.nbody, m.njnt, m.ngeom)"
```

## 4. 期待結果

以下を期待結果とする。

- Python が終了コード 0 で終了する
- `ok` が表示される
- `nbody` が 1 以上である
- `ngeom` が 1 以上である

## 5. 失敗時の確認観点

### 5.1 mujoco import に失敗する

確認すること：

- 仮想環境が有効化されているか
- `pip install -r requirements-dev.txt` が成功しているか
- Python バージョンが対応範囲内か

### 5.2 model.xml が見つからない

確認すること：

- リポジトリ直下でコマンドを実行しているか
- `examples/minimal_body/model.xml` が存在するか

### 5.3 viewer が起動しない

GUI viewer は初期完了条件に含めない。

viewer が失敗しても、headless の読み込みと `mj_step` が成功していれば、初期ローカル検証は成功とする。

## 6. テスト化方針

手動確認後、同等の確認を `pytest` で実行できるようにする。

初期テスト候補：

- T-LOCAL-001: `mujoco` を import できる
- T-LOCAL-002: `examples/minimal_body/model.xml` を読み込める
- T-LOCAL-003: `MjData` を生成できる
- T-LOCAL-004: `mj_step` を 1 回以上実行できる
- T-LOCAL-005: body / geom 数が期待範囲内である

## 7. 完了条件

本手順の完了条件は以下とする。

- 手動確認が成功する
- 失敗時の原因切り分け手順が明確である
- 同等の確認をテスト化する方針が定義されている
