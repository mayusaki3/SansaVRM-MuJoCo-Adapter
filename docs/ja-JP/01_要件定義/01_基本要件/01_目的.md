# 目的

## 1. 本リポジトリの目的

SansaVRM-MuJoCo-Adapter は、SansaVRM と MuJoCo / MJCF / controller configuration を接続する Adapter として、MuJoCo 固有の変換、近似、シミュレーション補助、検証処理を管理することを目的とする。

本リポジトリは、SansaVRM 本体に MuJoCo 実行環境への直接依存を持ち込まず、MuJoCo 連携に必要な処理を Adapter として分離する。

## 2. 背景

SansaVRM は、VRM 0.x / VRM 1.0 / URDF などのファイル変換対象に加え、MuJoCo との連携を想定する。

MuJoCo は単なるファイル形式変換だけではなく、以下を含む。

- MJCF 生成
- 物理パラメータ変換
- アクチュエータ写像
- controller configuration 生成
- MuJoCo 固有パラメータの解釈
- シミュレーション実行補助
- 変換レポート生成
- diagnostics 生成
- MuJoCo バージョン差分への追従

そのため、MuJoCo 連携は SansaVRM 本体の標準ファイル変換機能とは分離して扱う。

## 3. 実現したいこと

本リポジトリでは、以下の実現を目指す。

- SansaVRM から MJCF への変換
- MJCF に直接出力できる情報と Adapter 側補助成果物へ分離する情報の分類
- SansaVRM の actuator / sensor / physics / custom parameter 情報の MuJoCo 向け写像
- controller_config の生成
- conversion_report の生成
- diagnostics の生成
- ローカル MuJoCo 環境での最小動作確認
- 将来的な MJCF から SansaVRM への読み戻し検討

## 4. 設計上の基本姿勢

本リポジトリは、SansaVRM 本体の内部データ構造へ直接依存しない。

本 Adapter は、SansaVRM 本体が提供する安定した公開 API を経由して情報を取得する。

MuJoCo 固有の判断、近似、実行補助、検証は本 Adapter 側で扱う。

## 5. 非目的

本リポジトリは、以下を目的としない。

- SansaVRM 本体仕様の定義
- SansaVRM validator 本体の実装
- VRM / URDF の標準変換実装
- MuJoCo runtime 全体の実装
- 強化学習環境の実装
- リアルタイムネットワーク同期
- UI / editor 実装
