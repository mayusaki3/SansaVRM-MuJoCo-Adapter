# 責務境界

## 1. 本ドキュメントの目的

本ドキュメントは、SansaVRM 本体と SansaVRM-MuJoCo-Adapter の責務境界を定義する。

責務境界は、SansaVRM 本体に MuJoCo 実行環境への直接依存を持ち込まないために定義する。

## 2. 基本方針

SansaVRM 本体は、MuJoCo 連携に必要な共通情報と Adapter 向け API を提供する。

SansaVRM-MuJoCo-Adapter は、SansaVRM 本体 API から取得した情報をもとに、MuJoCo 固有の変換、近似、補助成果物生成、検証を行う。

Adapter は、SansaVRM 本体の内部データ構造へ直接依存してはならない。

## 3. SansaVRM本体の責務

SansaVRM 本体は、以下を担当する。

- SansaVRM 共通仕様の管理
- Module / Connection / Slot / Property の共通表現
- 物理モデル情報の保持
- ジョイント情報の保持
- コライダー情報の保持
- アクチュエータ情報の保持
- センサ情報の保持
- Adapter が参照する入出力 API の提供
- namespace 付き custom parameter の保持
- custom parameter schema の管理
- MJCF 入出力可否の判定に必要な schema 情報の保持
- Adapter から返却された diagnostics の保持

## 4. SansaVRM-MuJoCo-Adapterの責務

SansaVRM-MuJoCo-Adapter は、以下を担当する。

- SansaVRM API からの情報取得
- SansaVRM から MJCF への変換
- 必要に応じた MJCF から SansaVRM への変換
- MuJoCo actuator への写像
- controller_config の生成
- MuJoCo 固有パラメータの解釈
- MuJoCo 固有の近似変換
- diagnostics の生成
- conversion_report の生成
- MuJoCo 実行環境に依存する検証

## 5. 入出力境界

SansaVRM 本体と Adapter の入出力境界は、SansaVRM 本体が提供する公開 API とする。

Adapter は、以下の情報を API 経由で取得する。

- model metadata
- modules
- connections
- slots
- properties
- physics parameters
- joints
- colliders
- actuators
- sensors
- custom parameters
- custom parameter schemas

## 6. MJCFと補助成果物の境界

MJCF へ直接出力できる情報は、SansaVRM 側の custom parameter schema に定義された `io_scope` と `mjcf_mapping` に基づいて判定する。

MJCF へ直接出力しない情報は、`adapter_artifact` に基づき、controller_config などの Adapter 側補助成果物へ分離する。

この判定を実装側の推測で行ってはならない。

## 7. 非可逆情報の扱い

変換により完全再現できない情報、未対応情報、fallback 適用情報は diagnostics または conversion_report に記録する。

必要に応じて、SansaVRM 本体側の source_raw または custom parameter として保持する。

## 8. 変更時の原則

責務境界を変更する場合は、以下の順に更新する。

1. 要件定義
2. 仕様
3. テスト仕様
4. 実装計画
5. トレーサビリティ
