# ローカル検証要件

## 1. 本ドキュメントの目的

本ドキュメントは、SansaVRM-MuJoCo-Adapter のローカル検証環境に求める要件を定義する。

ローカル検証環境は、MuJoCo / MJCF 連携の最小動作確認、Adapter 実装前の前提確認、将来の自動テスト化の基盤として使用する。

## 2. 基本方針

ローカル検証環境は、初期段階では headless 実行を優先する。

GUI viewer は補助的な確認手段とし、初期完了条件には含めない。

ローカル検証環境は、SansaVRM 本体に依存せず、最小 MJCF モデルを用いて MuJoCo の読み込みと step 実行を確認できなければならない。

## 3. 対象環境

初期検証対象は以下とする。

- Windows 10 / Windows 11
- PowerShell
- Python 3.10 以上
- Python 仮想環境 `.venv`
- PyPI package `mujoco`

Linux / macOS は、別途検証後に対象へ追加する。

## 4. 必須要件

ローカル検証環境は、以下を満たさなければならない。

- 仮想環境をリポジトリ直下に作成できる
- `requirements-dev.txt` に基づき依存関係をインストールできる
- `mujoco` package を import できる
- 最小 MJCF モデルを読み込める
- `MjModel` を生成できる
- `MjData` を生成できる
- `mj_step` を 1 回以上実行できる
- body / joint / geom 数を取得できる
- ローカル生成物が Git 管理対象外となる

## 5. Git管理要件

以下は Git 管理対象外とする。

- `.venv/`
- `.env`
- `.env.*`
- `output/`
- `outputs/`
- `artifacts/`
- `logs/`
- `*.log`
- `*.mjb`
- `*.mjcf.compiled.xml`
- `controller_config.local.json`
- `conversion_report.local.json`
- `diagnostics.local.json`
- `local/`
- `tmp/`
- `temp/`
- `sandbox/`
- `assets/local/`
- `models/local/`

以下は Git 管理対象とする。

- `requirements-dev.txt`
- `.gitignore`
- `docs/`
- `examples/`
- `schemas/`
- `src/`
- `tests/`

ただし、`examples/` 配下でも巨大なバイナリ、外部から取得したモデル、個別環境依存の成果物は Git 管理対象外とする。

## 6. 最小検証モデル要件

最小検証モデルは、以下を満たす MJCF ファイルとする。

- MuJoCo で読み込める
- `worldbody` を持つ
- 1つ以上の `geom` を持つ
- 1つ以上の `body` を持つ
- headless 実行で `mj_step` できる
- GUI viewer がなくても検証できる

初期最小検証モデルは以下に配置する。

```text
examples/mujoco/minimal_body/model.xml
```

## 7. 手動確認要件

手動確認では、以下を確認する。

- `import mujoco` が成功する
- `examples/mujoco/minimal_body/model.xml` を読み込める
- `MjData` を生成できる
- `mj_step` が成功する
- `nbody` が 1 以上である
- `ngeom` が 1 以上である

## 8. 自動テスト化要件

手動確認後、同等の確認を `pytest` により自動化する。

初期テストは以下とする。

- T-LOCAL-001: `mujoco` を import できる
- T-LOCAL-002: `examples/mujoco/minimal_body/model.xml` を読み込める
- T-LOCAL-003: `MjData` を生成できる
- T-LOCAL-004: `mj_step` を 1 回以上実行できる
- T-LOCAL-005: body / geom 数が期待範囲内である

## 9. 完了条件

ローカル検証要件の初期完了条件は以下とする。

- `.gitignore` が定義されている
- `requirements-dev.txt` が定義されている
- 最小 MJCF モデルが配置されている
- ローカル環境構築手順が定義されている
- ローカル動作確認手順が定義されている
- headless で最小 MJCF モデルを読み込み、`mj_step` を実行できる

## 10. 次工程

本要件を満たした後、以下へ進む。

1. ローカル動作確認テスト仕様の作成
2. `pytest` による headless テスト実装
3. position actuator サンプルの追加
4. motor actuator サンプルの追加
5. controller_config schema の追加
