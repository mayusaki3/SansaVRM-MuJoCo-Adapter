# 対象範囲

## 1. 本ドキュメントの目的

本ドキュメントは、SansaVRM-MuJoCo-Adapter が扱う対象範囲を定義する。

対象範囲は、SansaVRM 本体、SansaVRM Extension Property、MuJoCo / MJCF、Adapter 側補助成果物、runtime 連携成果物、ローカル検証環境の境界を明確にするために定義する。

## 2. 対象とする入力

本 Adapter は、以下の入力を対象とする。

- SansaVRM 本体 API から取得できるモデル情報
- SansaVRM 本体 API から取得できる Module 情報
- SansaVRM 本体 API から取得できる Connection 情報
- SansaVRM 本体 API から取得できる Slot 情報
- SansaVRM 本体 API から取得できる Property 情報
- 物理モデル情報
- ジョイント情報
- コライダー情報
- アクチュエータ情報
- センサ情報
- Extension Property
- Extension Property Schema
- custom parameter
- custom parameter schema
- source_raw
- normalized_value

custom parameter は、Extension Property の一種として扱う。

## 3. 対象とする出力

本 Adapter は、以下の出力を対象とする。

- MJCF ファイル
- controller_config
- runtime_requirements
- updated_extension_properties
- conversion_report
- diagnostics
- MuJoCo 検証用サンプル

## 4. 対象とするMuJoCo要素

本 Adapter は、初期段階では以下の MuJoCo / MJCF 要素を対象とする。

- body
- joint
- geom
- actuator
- sensor
- site
- material
- mesh
- option
- default

以下は、将来拡張対象とする。

- tendon
- equality constraint
- contact pair
- exclude
- advanced solver parameter
- plugin
- keyframe

## 5. Extension Propertyとして扱う情報

以下の情報は、SansaVRM Core 標準仕様へ直接組み込まれることを前提にせず、Extension Property として扱う。

- device_category
- device_identity
- capability_profile
- command_semantics
- command_transport
- actuator_model
- behavior_model
- sysid_result_ref
- runtime_requirements
- HIL / SIL metadata
- Project Meridian runtime metadata
- controller_config metadata
- diagnostics_ref
- conversion_report_ref
- source_raw

## 6. 初期優先範囲

初期優先範囲は以下とする。

1. 最小 MJCF モデルの読み込み検証
2. Extension Property / custom parameter の分類
3. body / joint / geom の最小出力
4. position actuator の出力
5. motor actuator の出力
6. actuator parameter mapping
7. controller_config 生成
8. runtime_requirements 生成
9. diagnostics / conversion_report 生成

## 7. 対象外

初期段階では、以下を対象外とする。

- SansaVRM 本体仕様の定義
- SansaVRM Core 標準仕様への MuJoCo / Project Meridian / sysid / HIL-SIL 固有情報の統合
- SansaVRM validator 本体の実装
- VRM 0.x / VRM 1.0 変換実装
- URDF 変換実装
- MuJoCo runtime 全体の実装
- Project Meridian / meridian-mujoco-runtime の実装
- sysid optimizer の実装
- HIL / SIL bridge の実装
- 実ボード通信
- device specific driver
- ニソコンVRの試合・ルール・判定・進行管理
- 強化学習環境の実装
- リアルタイムネットワーク同期
- UI / editor 実装

## 8. 対象範囲の拡張方針

対象範囲を拡張する場合は、以下の順に定義する。

1. 要件定義への追記
2. 仕様への追記
3. テスト仕様への追記
4. 実装計画への追記
5. 必要に応じたトレーサビリティ更新
