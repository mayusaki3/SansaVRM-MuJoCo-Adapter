# 成果物仕様

## 1. 本ドキュメントの目的

本ドキュメントは、SansaVRM-MuJoCo-Adapter が生成または管理する成果物の種類、役割、配置方針、Git 管理方針を定義する。

成果物仕様は、MJCF、controller_config、conversion_report、diagnostics などの出力を整理し、SansaVRM 本体との責務境界を明確にするために定義する。

## 2. 成果物の分類

本 Adapter が扱う成果物は、以下に分類する。

- MuJoCo 実行用成果物
- Adapter 補助成果物
- 変換結果成果物
- 診断成果物
- 検証用サンプル成果物
- ローカル生成成果物

## 3. MuJoCo実行用成果物

MuJoCo 実行用成果物は、MuJoCo が直接読み込む、または MuJoCo 実行に直接使用する成果物である。

初期対象は以下とする。

- MJCF XML ファイル
- MuJoCo compiled binary model

### 3.1 MJCF XMLファイル

MJCF XML ファイルは、MuJoCo が読み込む物理モデル定義である。

標準的な出力名は以下とする。

```text
model.xml
```

MJCF XML ファイルには、以下を含める。

- body
- joint
- geom
- actuator
- sensor
- site
- material
- mesh
- option
- default

### 3.2 MuJoCo compiled binary model

MuJoCo compiled binary model は、MuJoCo が生成する compiled model である。

拡張子は以下を想定する。

```text
*.mjb
```

compiled binary model はローカル生成物として扱い、原則として Git 管理対象外とする。

## 4. Adapter補助成果物

Adapter 補助成果物は、MJCF へ直接出力しない制御・実行補助情報を保持する成果物である。

初期対象は以下とする。

- controller_config
- runtime_config
- external_metadata

### 4.1 controller_config

controller_config は、MJCF に直接出力しない制御関連情報を保持する。

標準的な出力名は以下とする。

```text
controller_config.json
```

controller_config には、以下のような情報を含める。

- command delay
- deadband
- external PID configuration
- thermal model settings
- current limit
- voltage limit
- runtime control mode
- actuator update rate

### 4.2 runtime_config

runtime_config は、MuJoCo 実行時の補助設定を保持する。

初期段階では、runtime_config は将来拡張対象とする。

### 4.3 external_metadata

external_metadata は、MJCF または controller_config に直接含めない外部補助情報を保持する。

初期段階では、external_metadata は将来拡張対象とする。

## 5. 変換結果成果物

変換結果成果物は、SansaVRM から MuJoCo 関連成果物への変換結果を記録する成果物である。

初期対象は以下とする。

- conversion_report

### 5.1 conversion_report

conversion_report は、変換結果の概要を記録する。

標準的な出力名は以下とする。

```text
conversion_report.json
```

conversion_report には、以下のような情報を含める。

- 変換元情報
- 変換先情報
- 変換対象数
- 変換成功数
- 変換除外数
- fallback 適用結果
- 非可逆変換情報
- warning 情報
- unsupported parameter 情報

## 6. 診断成果物

診断成果物は、変換、検証、実行前確認で検出した警告・エラー・補足情報を記録する成果物である。

初期対象は以下とする。

- diagnostics

### 6.1 diagnostics

diagnostics は、検証・警告・エラー情報を記録する。

標準的な出力名は以下とする。

```text
diagnostics.json
```

diagnostics には、以下のような情報を含める。

- missing required parameter
- unsupported MuJoCo parameter
- unsupported target MuJoCo version
- invalid custom parameter schema
- invalid joint tree structure
- fallback applied
- non-reversible conversion

## 7. 検証用サンプル成果物

検証用サンプル成果物は、Adapter の検証に使用する最小モデル、サンプルモデル、期待結果を指す。

初期配置は以下とする。

```text
examples/mujoco/
```

初期対象は以下とする。

```text
examples/mujoco/minimal_body/model.xml
```

検証用サンプル成果物は、サイズが小さく、外部依存がなく、再現性があるものに限り Git 管理対象とする。

## 8. ローカル生成成果物

ローカル生成成果物は、開発者のローカル環境で生成される一時成果物である。

以下は Git 管理対象外とする。

- `output/`
- `outputs/`
- `artifacts/`
- `logs/`
- `*.log`
- `*.mjb`
- `*.mjcf.compiled.xml`
- `controller_config.local.json`
- `conversion_report.local.json`
- `diagnostics.local.json`

## 9. Git管理方針

### 9.1 Git管理対象

以下は Git 管理対象とする。

- 仕様ドキュメント
- テスト仕様ドキュメント
- 小規模な検証用 MJCF サンプル
- schema ファイル
- Adapter 実装コード
- テストコード

### 9.2 Git管理対象外

以下は Git 管理対象外とする。

- ローカル仮想環境
- ローカル出力成果物
- ローカルログ
- compiled binary model
- 外部から取得した巨大モデル
- 個別環境依存の設定ファイル

## 10. 成果物配置方針

標準的な配置方針は以下とする。

```text
output/
├─ model.xml
├─ controller_config.json
├─ conversion_report.json
└─ diagnostics.json
```

ただし、`output/` 配下はローカル生成物として扱い、Git 管理対象外とする。

## 11. 命名方針

成果物名は、原則として役割が分かる名称とする。

初期標準名は以下とする。

- `model.xml`
- `controller_config.json`
- `conversion_report.json`
- `diagnostics.json`

ローカル専用ファイルには `.local` を含める。

例：

- `controller_config.local.json`
- `conversion_report.local.json`
- `diagnostics.local.json`

## 12. 非スコープ

本ドキュメントでは、以下を非スコープとする。

- 各 JSON 成果物の詳細 schema
- MJCF XML 生成アルゴリズム
- MuJoCo runtime 実装
- SansaVRM 本体の成果物仕様
- VRM / URDF 変換成果物仕様
