# 仕様概要

## 1. 本ドキュメントの目的

本ドキュメントは、SansaVRM-MuJoCo-Adapter の共通仕様の概要を定義する。

本仕様は、SansaVRM 本体と MuJoCo / MJCF / controller configuration を接続する Adapter の全体像、入出力、成果物、責務境界を示す。

## 2. 基本方針

SansaVRM-MuJoCo-Adapter は、SansaVRM 本体の内部データ構造に直接依存しない。

Adapter は、SansaVRM 本体が提供する公開 API を経由して情報を取得する。

MuJoCo 固有の変換、近似、補助成果物生成、実行環境依存の検証は Adapter 側で扱う。

## 3. 入力

本 Adapter の入力は、SansaVRM 本体 API から取得する情報を基本とする。

主な入力は以下とする。

- model metadata
- modules
- connections
- slots
- properties
- physics parameters
- joints
- colliders
- actuators
- sensors
- custom parameters
- custom parameter schemas

## 4. 出力

本 Adapter の出力は以下とする。

- MJCF ファイル
- controller_config
- conversion_report
- diagnostics

## 5. MJCFファイル

MJCF ファイルは、MuJoCo が読み込む物理モデル定義である。

初期段階では、以下の要素を対象とする。

- body
- joint
- geom
- actuator
- sensor
- site
- material
- mesh
- option
- default

## 6. controller_config

controller_config は、MJCF に直接出力しない制御・実行補助情報を保持する成果物である。

controller_config には、以下のような情報を含める。

- command delay
- deadband
- external PID configuration
- thermal model settings
- current limit
- voltage limit
- runtime control mode
- actuator update rate

## 7. conversion_report

conversion_report は、変換結果の概要を記録する成果物である。

conversion_report には、以下のような情報を含める。

- converted elements
- skipped elements
- fallback results
- non-reversible conversions
- warnings
- unsupported parameters

## 8. diagnostics

diagnostics は、検証・警告・エラー情報を記録する成果物である。

diagnostics には、以下のような情報を含める。

- missing required parameter
- unsupported MuJoCo parameter
- unsupported target MuJoCo version
- invalid custom parameter schema
- invalid joint tree structure

## 9. custom parameter schema連携

MuJoCo 固有パラメータは、SansaVRM 側の custom parameter schema に基づいて扱う。

custom parameter schema では、各パラメータが以下のどれに該当するかを識別する。

- MJCF に直接入出力できる
- Adapter 側補助成果物へ分離する
- MJCF と Adapter 側補助成果物の両方へ出力する
- SansaVRM 内に保持するのみ
- 現在は未対応
- source_raw として保持する

## 10. 初期実装優先範囲

初期実装では、以下を優先する。

1. 最小 MJCF モデルの読み込み検証
2. body / joint / geom の最小変換
3. position actuator の出力
4. motor actuator の出力
5. controller_config の生成
6. diagnostics / conversion_report の生成

## 11. 非スコープ

本仕様概要では、以下を非スコープとする。

- SansaVRM 本体仕様の定義
- SansaVRM validator 本体の実装
- VRM / URDF 標準変換実装
- MuJoCo runtime 全体の実装
- 強化学習環境の実装
- リアルタイムネットワーク同期
- UI / editor 実装
