# 仕様概要

## 1. 本ドキュメントの目的

本ドキュメントは、SansaVRM-MuJoCo-Adapter の共通仕様の概要を定義する。

本仕様は、SansaVRM 本体と MuJoCo / MJCF / controller configuration / Project Meridian runtime を接続する Adapter の全体像、入出力、成果物、責務境界を示す。

## 2. 基本方針

SansaVRM-MuJoCo-Adapter は、SansaVRM 本体の内部データ構造に直接依存しない。

Adapter は、SansaVRM 本体が提供する公開 API を経由して情報を取得する。

Adapter は、SansaVRM Core 標準構造と SansaVRM Extension Property を分けて扱う。

MuJoCo / Project Meridian / sysid / HIL-SIL 固有情報は、SansaVRM Core 標準仕様ではなく Extension Property として扱う。

MuJoCo 固有の変換、近似、補助成果物生成、実行環境依存の検証は Adapter 側で扱う。

ただし、MuJoCo runtime の継続実行、sysid、HIL / SIL、実ボード同期、ニソコンVRの試合・ルール・判定・進行管理は Adapter の責務外とする。

## 3. 入力

本 Adapter の入力は、SansaVRM 本体 API から取得する情報を基本とする。

主な入力は以下とする。

- model metadata
- modules
- connections
- slots
- properties
- physics parameters
- joints
- colliders
- actuators
- sensors
- extension properties
- extension property schemas
- custom parameters
- custom parameter schemas

custom parameter は Extension Property の一種として扱う。

## 4. 出力

本 Adapter の出力は以下とする。

- MJCF ファイル
- controller_config
- runtime_requirements
- updated_extension_properties
- conversion_report
- diagnostics

## 5. MJCFファイル

MJCF ファイルは、MuJoCo が読み込む物理モデル定義である。

初期段階では、以下の要素を対象とする。

- body
- joint
- geom
- actuator
- sensor
- site
- material
- mesh
- option
- default

## 6. controller_config

controller_config は、MJCF に直接出力しない制御・実行補助情報を保持する Adapter 側補助成果物である。

controller_config には、以下のような情報を含める。

- command delay
- deadband
- external PID configuration
- thermal model settings
- current limit
- voltage limit
- runtime control mode
- actuator update rate
- diagnostics_ref
- conversion_report_ref

## 7. runtime_requirements

runtime_requirements は、Project Meridian / meridian-mujoco-runtime などの外部 runtime が必要とする機能要求を保持する runtime 連携成果物である。

runtime_requirements には、以下のような情報を含める。

- required_runtime
- required_runtime_version
- requires_external_control_loop
- requires_sysid_result
- requires_hil
- requires_sil
- requires_sensor_frame
- requires_contact_events
- required_features

runtime_requirements は、Adapter が runtime を実装するための成果物ではない。

## 8. updated_extension_properties

updated_extension_properties は、Adapter または meridian-mujoco-runtime 由来の更新結果を SansaVRM Extension Property として再格納するための候補成果物である。

updated_extension_properties は、SansaVRM Core 標準仕様を変更するものではない。

## 9. conversion_report

conversion_report は、変換結果の概要を記録する成果物である。

conversion_report には、以下のような情報を含める。

- converted elements
- skipped elements
- fallback results
- non-reversible conversions
- warnings
- unsupported parameters
- Extension Property classification results
- runtime artifact separation results

## 10. diagnostics

diagnostics は、検証・警告・エラー情報を記録する成果物である。

diagnostics には、以下のような情報を含める。

- missing required parameter
- unsupported MuJoCo parameter
- unsupported target MuJoCo version
- invalid Extension Property Schema
- invalid custom parameter schema
- invalid joint tree structure
- runtime artifact separation
- source_raw handling

## 11. Extension Property Schema連携

MuJoCo / Project Meridian / sysid / HIL-SIL 固有情報は、SansaVRM 側の Extension Property Schema に基づいて扱う。

Extension Property Schema では、各拡張プロパティが以下のどれに該当するかを識別する。

- MJCF に直接入出力できる
- Adapter 側補助成果物へ分離する
- runtime 側成果物へ分離する
- MJCF と Adapter 側補助成果物の両方へ出力する
- SansaVRM 内に保持するのみ
- 現在は未対応
- source_raw として保持する

## 12. custom parameter schema連携

custom parameter schema は、Extension Property Schema の一部または互換 schema として扱う。

既存の custom parameter は、Extension Property の一種として扱う。

## 13. 初期実装優先範囲

初期実装では、以下を優先する。

1. 最小 MJCF モデルの読み込み検証
2. Extension Property / custom parameter の分類
3. body / joint / geom の最小変換
4. position actuator の出力
5. motor actuator の出力
6. controller_config の生成
7. runtime_requirements の生成
8. diagnostics / conversion_report の生成

## 14. 非スコープ

本仕様概要では、以下を非スコープとする。

- SansaVRM 本体仕様の定義
- SansaVRM Core 標準仕様への MuJoCo 固有情報の統合
- SansaVRM validator 本体の実装
- VRM / URDF 標準変換実装
- MuJoCo runtime 全体の実装
- Project Meridian runtime の実装
- sysid optimizer の実装
- HIL / SIL bridge の実装
- ニソコンVRの試合・ルール・判定・進行管理
- 強化学習環境の実装
- リアルタイムネットワーク同期
- UI / editor 実装
