# アクチュエータ写像

## 1. 本ドキュメントの目的

本ドキュメントは、SansaVRM-MuJoCo-Adapter における SansaVRM のアクチュエータ情報から MuJoCo actuator への写像方針を定義する。

本仕様は、実サーボ、BLDC サーボ、DC モーター、トルク制御、位置制御などの情報を、MJCF に直接出力する情報と controller_config などの Adapter 側補助成果物へ分離する情報に分類するために使用する。

## 2. 基本方針

アクチュエータ写像は、SansaVRM 本体 API から取得した actuator 情報と custom parameter schema に基づいて行う。

Adapter は、MJCF に直接出力できるかどうかを実装側の推測で判定してはならない。

MJCF へ直接出力する情報は、custom parameter schema の `io_scope` と `mjcf_mapping` に従う。

MJCF に直接出力しない情報は、custom parameter schema の `adapter_artifact` に従い、controller_config などの Adapter 側補助成果物へ分離する。

## 3. 入力情報

アクチュエータ写像では、以下の情報を入力とする。

- actuator id
- actuator name
- target joint
- control mode
- actuator type
- torque limit
- velocity limit
- position limit
- gear ratio
- kp
- kv
- current limit
- voltage limit
- command delay
- deadband
- update rate
- custom parameters
- custom parameter schema

## 4. 出力情報

アクチュエータ写像では、以下を出力する。

- MJCF actuator 要素
- controller_config の actuator 設定
- conversion_report の actuator 変換結果
- diagnostics の actuator 診断情報

## 5. MuJoCo actuator種別

初期段階では、以下の MuJoCo actuator 種別を対象とする。

- `position`
- `motor`
- `velocity`

以下は将来拡張対象とする。

- `general`
- `dcmotor`
- `muscle`
- plugin based actuator

## 6. control mode写像

SansaVRM の control mode は、初期段階では以下のように MuJoCo actuator へ写像する。

| SansaVRM control mode | MuJoCo actuator | 備考 |
| --- | --- | --- |
| `position` | `position` | 位置目標を入力する |
| `velocity` | `velocity` | 速度目標を入力する |
| `torque` | `motor` | トルクまたは力を入力する |
| `force` | `motor` | 直動系などで力を入力する |
| `external_controller` | `motor` + controller_config | 外部制御でトルクを生成する |
| `unknown` | 変換不可 | diagnostics に記録する |

## 7. position actuator写像

SansaVRM の位置制御アクチュエータは、MuJoCo の `position` actuator へ写像する。

初期対象属性は以下とする。

- name
- joint
- kp
- kv
- gear
- ctrlrange
- forcerange

### 7.1 ctrlrange

`ctrlrange` は、位置目標の範囲を表す。

SansaVRM 側に position limit が定義されている場合、`ctrlrange` へ写像する。

単位が degree の場合は、MJCF 出力前に radian へ変換する。

### 7.2 forcerange

`forcerange` は、出力トルクまたは力の範囲を表す。

SansaVRM 側に torque limit が定義されている場合、`forcerange` へ写像する。

単一の正の最大値として定義されている場合、初期方針では対称範囲として出力する。

例：

```text
torque_limit_nm = 3.5
forcerange = "-3.5 3.5"
```

### 7.3 kp / kv

`kp` と `kv` は、MuJoCo position actuator のゲインとして扱う。

実サーボの内部 PID と完全一致するとは限らないため、近似変換として扱う。

近似変換であることは、必要に応じて conversion_report または diagnostics に記録する。

## 8. velocity actuator写像

SansaVRM の速度制御アクチュエータは、MuJoCo の `velocity` actuator へ写像する。

初期対象属性は以下とする。

- name
- joint
- kv
- gear
- ctrlrange
- forcerange

速度制限が定義されている場合、`ctrlrange` へ写像する。

## 9. motor actuator写像

SansaVRM の torque / force control は、MuJoCo の `motor` actuator へ写像する。

初期対象属性は以下とする。

- name
- joint
- gear
- ctrlrange
- forcerange

`motor` actuator は、外部制御コードまたは controller_config と組み合わせて使用できる。

実サーボの内部制御を外部で再現する場合、MJCF には `motor` actuator を出力し、PID、遅延、デッドバンド、電流制限などは controller_config へ分離する。

## 10. gear写像

`gear` は、MuJoCo actuator の力・トルク変換係数として扱う。

SansaVRM 側に gear ratio が定義されている場合、MuJoCo の `gear` へ写像できる。

ただし、実サーボの減速比、出力軸換算、モーター軸換算、センサー軸換算が混在する場合は、写像基準を明確にし、diagnostics に記録する。

## 11. torque limit写像

SansaVRM 側の torque limit は、可能な場合 `forcerange` へ写像する。

電流制限からトルク制限を算出する場合は、算出式と前提値を conversion_report または diagnostics に記録する。

例：

```text
torque_limit = torque_constant * current_limit * gear_ratio * efficiency
```

必要な前提値が不足する場合は、fallback 方針に従う。

## 12. velocity limit写像

SansaVRM 側の velocity limit は、以下のいずれかへ写像する。

- velocity actuator の `ctrlrange`
- controller_config の velocity limit
- preserve_only

位置制御サーボの最大速度制限のように、MJCF の `position` actuator へ直接表現しにくい情報は controller_config へ分離する。

## 13. command delay写像

command delay は、MJCF に直接出力しない。

command delay は controller_config へ出力する。

出力先は custom parameter schema の `adapter_artifact` に従う。

## 14. deadband写像

deadband は、MJCF に直接出力しない。

deadband は controller_config へ出力する。

制御誤差が deadband 内にある場合の挙動は、controller runtime 側の仕様で定義する。

## 15. current limit / voltage limit写像

current limit と voltage limit は、原則として MJCF に直接出力しない。

以下のいずれかとして扱う。

- torque limit 算出に使用する
- controller_config へ出力する
- preserve_only として保持する

算出に使用した場合は、conversion_report または diagnostics に記録する。

## 16. thermal model写像

thermal model は、初期段階では MJCF に直接出力しない。

thermal model は controller_config または external_metadata へ分離する。

温度による出力低下、連続トルク制限、ピークトルク継続時間などは controller runtime 側の仕様で定義する。

## 17. 実サーボ近似方針

実サーボの挙動は、MuJoCo actuator と完全一致しない場合がある。

以下は近似変換として扱う。

- 内部 PID
- 位置保持制御
- 電流制限
- 温度保護
- 通信周期
- 指令遅延
- デッドバンド
- 加速度制限
- 最大速度制限

近似変換を行った場合は、diagnostics または conversion_report に記録する。

## 18. diagnostics記録対象

アクチュエータ写像では、以下を diagnostics に記録する。

- 未対応 actuator type
- 未対応 control mode
- 必須パラメータ不足
- torque limit 算出不能
- MJCF へ直接出力できないパラメータ
- controller_config へ分離したパラメータ
- fallback 適用
- 非可逆変換
- MuJoCo バージョン非対応

## 19. conversion_report記録対象

アクチュエータ写像では、以下を conversion_report に記録する。

- 変換対象 actuator 数
- 変換成功 actuator 数
- 変換除外 actuator 数
- MJCF へ出力した actuator 数
- controller_config へ分離した actuator parameter 数
- fallback 適用数
- warning 数
- error 数

## 20. 非スコープ

本ドキュメントでは、以下を非スコープとする。

- MuJoCo controller runtime の実装
- 実サーボ内部ファームウェアの完全再現
- FOC 制御の詳細実装
- ESC 制御の詳細実装
- 熱シミュレーションの詳細実装
- 強化学習環境の実装
